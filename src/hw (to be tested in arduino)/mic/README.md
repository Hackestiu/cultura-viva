# Bluetooth Bidirectional Audio

Both `Manual` and `Automatic` are test builds intended to be packaged
into a ZIP file and uploaded directly to physical hardware for testing.
The button-toggle version is currently stable and verified. The
automatic version is experimental and requires further App Lab testing.

Install `bluez`, `bluealsa`, and `alsa-utils` on the UNO Q Linux image.
Those packages provide `bluetoothctl`, `bluealsa`, `arecord`, and
`aplay`. Detailed installation and profile checks are in each README.

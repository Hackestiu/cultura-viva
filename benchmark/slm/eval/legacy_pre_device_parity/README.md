# Legacy predictions (pre device-parity)

These five prediction sets were generated by the older benchmark, and are kept
only for before/after comparison. **They are not comparable to current runs.**

They were produced with:

- a single flat completion prompt (`/api/generate`) under a generic
  "CulturaViva" persona, rather than the device's chat prompt with facts first
  and one of three guide personalities second;
- `max_tokens=128`, no `repeat_penalty`, no stop sequences — the device uses
  60, 1.1, and `["\n\n", "<|im_end|>"]`;
- a knowledge base of 12 element sheets. The device has 24; the missing half was
  every Sagrada Família and Casa Batlló element, so questions about those
  monuments were answered from whatever the semantic retriever found instead.

Current runs are written to `eval/predictions_<model>_<personality>.json`.
Regenerate with `uv run python main.py benchmark`.
